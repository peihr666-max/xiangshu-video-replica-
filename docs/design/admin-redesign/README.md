## 历史版本

- **`native-style/`**（2026-09-03）：新能力 + 现有后台原样式（暖账本深色主题）12 页——第一轮"只改内容与布局"的落地形态，其中设备/会话/激活码/审计等页的改版点仍有效（未受第二轮需求影响的部分以该版为准）。
- 根目录 12 张（v1）：浅色 Ant 风格初版，仅作对照。

- **`native-style/`（当前评审基准）**：新能力 + **现有后台原样式**（暖账本深色主题：暖炭黑 #131313 画布、镜序 Studio 品牌侧栏、金色强调 #c6a45f、#181818 大圆角面板、深底描边胶囊徽章）——即"只改内容与布局、不改样式"的落地形态。
- 根目录 12 张（v1）：新能力 + 通用浅色 Ant 风格（初版参考，已被 native-style 版取代）。

生成方式：`bash run-one.sh <slug>`（两目录各自独立；提示词在各自 `prompts/`，可改后重跑单页）。
下表的文件列对两个版本同名通用（native-style/ 下为最终版）。

## 设计决议记录

- 2026-09-03 发码流程：采纳"创建即发放"——UI 一步完成（表单合并发放字段），服务端保留 GENERATED→ISSUED 状态机作为纵深（防批量预生成时库存泄露即可用），同事务自动翻转并记审计事件；一次性明文下载审计保留不变。
