## 设计决议记录

- 2026-09-03 发码流程：采纳"创建即发放"——UI 一步完成（表单合并发放字段），服务端保留 GENERATED→ISSUED 状态机作为纵深（防批量预生成时库存泄露即可用），同事务自动翻转并记审计事件；一次性明文下载审计保留不变。
