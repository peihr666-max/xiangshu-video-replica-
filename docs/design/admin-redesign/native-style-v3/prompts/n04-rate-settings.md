区块二「对外售价（按秒计费）」表格，列：档位、计价单位、当前售价、生效自、更新人、操作。两行：768P（0.12 元/秒，09-01，admin-phlong）、2K（0.20 元/秒，09-01，admin-phlong）；右上「+ 新增档位」。
区块三「历史变更（最近 5 条）」小表：时间、科目、旧值→新值（如 0.09 → 0.12，旧值灰字删除线、新值加粗）、原因（「2K 产能紧张上调」）、操作人。
