# 众墅之家 AI 即创 · V1.2 修改说明

日期：2026-09-05。交付对象：产品与前端界面审核。

本版基于 V1.1 的逐页审核结果修订，保留黑金配色、众墅之家品牌与乡墅行业语境。原 V1.1 文件夹保持独立，本版不覆盖原稿。

## 本轮重点

1. **五视图是一张图片。** 人物详情用一个完整的拼合图容器展示五个视角，整张放大、整张下载，不再拆成五张独立 UI 卡片。
2. **一个人物可以有多套场景形象。** 基准身份与场景照片分区：例如张工的庭院讲解、工地巡查、设计讲解。每套场景有自己的预览和五视图入口，使用场景不等于新建人物。
3. **新增爆款视频。** 用于整理乡墅参考作品、收藏、查看来源、带入复刻。当前设计按导入的参考库表达，不承诺全网抓取、实时榜单或素材可任意商用。
4. **整合创作侧栏。** 创作区只保留爆款视频、视频创作、文案工坊。工作台与任务中心上移为常驻入口。
5. **修正业务状态与数字。** 区分源视频时长、生成片段时长、等待时间与生成耗时；修正任务分页、数据看板口径和部分成功批次。
6. **补上关键状态。** 增加生成前确认、空态、上传失败、余额不足与发布账号未连接的设计示意。

## 本版边界

- 19 张图片是界面设计稿，不是可运行的业务前端。审核 HTML 可翻页、记录意见和导出意见；图中的业务按钮不可直接操作真实任务。
- 继续沿用当前产品的“条数”表达。图中的预计扣除和余额是审核示例，不代表真实定价；最终报价须由服务端在提交前返回。
- 画面比例完整保留自动、21:9、16:9、4:3、1:1、3:4、9:16。具体模型、时长、分辨率、首尾帧和多参考组合的可用性仍需实施时做能力校验，不应仅凭效果图开放全部组合。
- 爆款导入、跨平台发布和数据汇总仍需明确来源、账号授权、平台能力与实际接入范围；此轮未执行对外发布或采集。
- 人物照片和乡墅案例为设计示例，正式替换应使用有授权的企业素材。人物基准图与场景五视图复用现有单张拼合图的数据关系。
- 不以效果图验收代替功能测试、真实接口测试或生产验收。
