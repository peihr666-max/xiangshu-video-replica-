# V1.2 审核包使用说明

双击同文件夹内的 `00-打开审核.html`，或打开本次提供的本地审核地址。全部图片与文档均在此文件夹中，不依赖第三方图床。

## 如何审核

1. 点击缩略图查看完整效果图；使用上一张、下一张或左右方向键翻页，Esc 关闭。
2. 在各卡片的“填写审核意见”中选择待审核、通过或需调整，并写明“页面区域＋希望怎样改”。
3. 审核记录仅保存在当前浏览器环境中；结束前点击“导出审核意见”留存 Markdown 文件。换浏览器、清理缓存或更换本地地址可能无法自动带入记录。
4. V1.2 与 V1.1 使用不同的记录空间，不覆盖上一版意见。制作方视觉检查通过不等于用户审核通过，所有页面初始状态仍为待审核。

## 版本内容

19 张效果图：14 个主页面、3 个详情页、2 张状态补充。修改重点见 `00-V1.2修改说明.md`，逐页确认项见 `00-逐页审核清单.md`。

本包是黑金风格的乡墅 AI 视频创作界面方案；不是已部署产品，也没有运行收费生成、账号连接、充值、发布或生产配置变更。所有人物、参考来源、日期、统计和费用数值均为审核示例。

请重点确认：导航是否容易找到、单张五视图是否明确、场景形象是否属于对应人物、视频创作的模式切换是否清楚，以及错误发生时是否能找到下一步。
