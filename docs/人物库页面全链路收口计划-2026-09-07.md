# 人物库页面全链路收口计划（T46）

> 基线：`7f08678`，分支 `feat/character-library-page-closure`
>
> 状态：`IN_PROGRESS`
>
> 目标：以人物库页面为入口，收口“人物图片 → 多视图/场景 → IP 档案 → 分身/声音 → 数字人口播 → 任务与配置”的代码链路。
>
> 证据边界：本任务最高只能达到 `AUTOMATED_VERIFIED`；真实 Apilio/DeepSeek/Hifly/COS/钱包联合链仍归 T40，需单独授权。

## 1. 产品口径

1. 上传一张人物图片，生成一张五视图拼合图；后端可继续保留兼容下游所需的派生视角资产。
2. 场景形象以同一人物身份为边界，按场景和服装描述生成新的场景拼合图。
3. IP 档案必须实际进入文案二创请求，任务执行期间使用不可变档案快照。
4. 照片/视频分身、声音克隆、声音确认和数字人口播必须绑定同一人物与授权证据。
5. “标准口播”的字幕选项必须真实传到后端；“网感模板”属于后期合成模板，在没有模板渲染链前不得表现为已生效参数。
6. 任何不可解码图片、伪音频、空视频或提交结果未知，都不得被伪装成成功、自动重提付费请求或完成结算。

## 3. 页面级最终验收

| 页面 | 必须通过的用户路径 |
| --- | --- |
| 人物列表 | 新增、搜索/加载更多、真实数量、改名、删除和异常提示一致 |
| 基础形象 | 上传一张图后显示可解码拼合图；可下载；重新生成失败时保留旧版本 |
| 场景形象 | 场景与服装进入请求；第 13 条可加载；点击制作分身准确带图 |
| IP 档案 | 保存后重开可恢复；按 IP 二创真实携带 identity；不同人物结果隔离 |
| 口播分身 | 照片/视频素材、授权、状态和失败原因完整；UNKNOWN 不允许盲目重提 |
| 声音克隆 | 5–180 秒真实音频、授权、试听、确认和失败提示完整 |
| 数字人口播 | 文案/音频两模式互不串值；直接上传可用；字幕参数生效；提交单飞 |
| 任务中心 | 取消、下载、归档重试和人工核对动作与后端状态一致；无普通付费重提 |
| 设置 | Hifly 配置与口播单价可保存、读取、掩码和权限控制 |

所有页面还必须满足：auditor 不展示写入口，正式 API 失败不回退 review/mock，局部资源加载失败不清空整个人物列表。

## 4. 开发与提交顺序

每个增量先写失败测试，再做最小实现，单独提交：

1. `CL-00` 清单与证据骨架。
2. `CL-01` 付费任务与队列安全。
3. `CL-02/03` 图片及音视频有效性。
4. `CL-04` 权限与删除一致性。
5. `CL-05/06/07` 页面交接与口播参数。
6. `CL-08` 设置和迁移。
7. `CL-09` 分页、计数与未知状态。
8. `CL-10` 全仓门禁、独立复核和证据回填。

## 5. 回滚与外部依赖

- 代码提交逐包可 `git revert`；数据库字段使用独立可逆迁移，不删除历史列。
- 删除链只调整执行顺序，不批量清理现有生产对象。
- 本任务不自动调用真实付费 Provider、不修改生产 COS、不执行真实扣款或公网发布。
- `oral-ip-agents-research` 将网感模板定义为字幕/封面/BGM 的后期合成资产；在当前仓库没有对应模板渲染链前，本任务不猜测 Hifly 参数。
