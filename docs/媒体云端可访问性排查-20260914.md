## 音频传递规则

- 本地短音频：ffmpeg 生成单声道 16kHz M4A，确认时长不超过 300 秒且 Base64 Data URL 不超过 10,000,000 字节后，直接随 Flash 请求传给百炼。只是省去 COS 中转，识别仍在云端。
- COS 音频：保留预签名下载 URL。长音频使用异步提交、保存任务号、轮询同一任务。
- 本地长音频、时长未知、超限输入：在记录付费尝试之前拒绝，提示缩短/压缩或启用云存储后重新上传。没有实现分段转写或后台隐式迁移。
- 供应商错误不回显原始响应或音频 URL，仅保留 HTTP 状态和通过 UUID 校验的请求引用用于排查。
