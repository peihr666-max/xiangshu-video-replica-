# 视频复刻与人物替换 · 模块拆分实施记录（2026-09-07）

> 范围：把成熟工作区（AnalysisWorkspace/ProjectDetailFlow）耦合的"复刻"与"置换首帧"能力拆分为 studio 独立模块。后端能力全部已实现（analysis/shot-cards/scripts/prompts/first-frames/source-frames/character-reference 各域），本轮为**纯前端拆分接线 + 零后端新增**，延续 C2 视频生成的独立创作范式。
> 分支：模块①`feat/studio-replica-flow`、模块②`feat/studio-replacement-flow`，各自独立开发→代码评审→全量门禁→合回共享线 `docs/project-tech-review-2026-09-07`。

## 模块 ①视频复刻（feat/studio-replica-flow）

**流程**：上传参考视频（复用工作台直传 createProject→upload-intent→upload→complete）或选择已有项目 → 启动 AI 拆解（POST analysis-tasks + waitForAnalysisTask 20 分钟轮询）→ **客户端落库 shot_card 版本**（saveShotCards——拆解任务只写 analysis 版本，这是与后端契约的关键一步）→ 分镜卡列表 → **可编辑拆解 Prompt**（逐镜头反推文本 + 原片口播稿，buildReplicaPromptText 拼装）→ 保存为自定义提示词（saveGenerationPrompt，进"我的提示词"，视频生成页可跨项目导入）→ 送生成（runReplicaGeneration：createScriptVersion→compile→编辑过则 revise→lock→createGenerationBatch，要求项目已有确认首帧，否则引导去人物替换页）。

**评审修复要点**：
- P0 拆解不产生 shot_card 版本（原实现漏 saveShotCards，主路径必断）；
- P0 客户时长档位归一（≤9s→4s，>9s→15s——项目批次管线对 customer 强制 {4,15}）；
- 换来源视频清理旧拆解状态 + 以 analysisProjectRef 防旧结果覆盖；空稿回退（原片口播稿→分镜台词→"纯画面叙事"）；首帧 selection stale 不再误判可用。

## 模块 ②人物替换（feat/studio-replacement-flow）

**流程**（组合 ProjectDetailFlow 已解耦的四个叶子组件，simplified 详情页模式）：选项目（下拉按 analysis_status=READY 过滤）→ ① CharacterSelection 选人物 IP → ② SourceFrameSelection 提取并确认源画面（传入拆解时长作为取帧边界）→ 自动匹配人物参考（selectCharacterReferences，角色版本×源画面组合只自动尝试一次，失败可手动重试）→ ③ FirstFrameSelection 生成置换首帧（五视图参考 + 质检标注）→ 确认后 `patchDraft({firstFrameId, frameConfirmed: true})`（补齐 frameConfirmed 生产置位路径）→ ④「用于文/图生视频」跳 i2v（first_frame kind 已在 independent 通道白名单；COS 要求由后端校验并透出文案）。

**评审修复要点**：
- P0 patchDraft 进 effect 依赖（每次壳层渲染新引用）导致无限置位循环 → patchDraftRef + confirmedAssetIdRef 同资产只置位一次；
- P0 两个 handler 未 useCallback → 叶子组件 effect 依赖回调身份引发重取风暴并反复清空下游 → 与正本一致 useCallback；
- P1 换人物/换源画面/换项目清理草稿旧首帧（防旧组合静默进入 i2v）；参考匹配失败加重试按钮；源画面取帧传入拆解时长；leafBusy 忙态防抖；项目下拉 READY 过滤。

## 两模块共同的行为边界

- 复刻页"送生成"与替换页产出的首帧是**接力关系**：复刻（拆解+Prompt）→ 替换（确认首帧）→ 生成（视频生成页 i2v 或复刻页送生成）。无首帧时引导而非静默失败。
- Prompt 编辑采用"编译产物 + 编辑修订"语义：未编辑直接锁定编译版本；编辑过则存修订版本再锁定——全部走既有 prompts 端点。
- 成熟工作区（AnalysisWorkspace）保持原样可用，"进入分镜工作区"作为高级入口保留；两模块与其共享同一套后端版本数据。
