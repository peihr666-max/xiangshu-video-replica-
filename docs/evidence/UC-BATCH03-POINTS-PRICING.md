## 实现与边界

后台发布带版本的积分配置：768P/2K 视频每秒价、口播每任务价、消费折扣（基点）、逐任务向上/下取整（最低 1 积分）、每元充值积分。读取、报价、受理预扣共用服务端配置；价格页另列出当前不单独扣分的解析、首帧、人物图片和提示词编译，0 积分不是上游成本。免费功能没有新增扣费入口；不将所有 HTTP 辅助接口称为收费 API。历史余额转换和管理员积分操作由第四批交付。

同账号全部凭据共用 wallets.user_id；会话操作标记 session，API 操作记录实际 key_id，Worker 结算/退款复制受理轮次的来源和价格快照，不依赖 Token 继续有效。数据库联合外键阻止 key 与用户错配；轮换保留稳定 Token 组。账单支持来源、Token 组、业务、类型、日期和分页；任务跳转传递前端任务 ID 与后台 ID，并返回个人中心。

充值按整数分×每元积分÷100 向下取整；订单固化版本/兑换率，不修改历史订单。支付未成功不会加分，原支付验签/统一结算继续有效。旧零金额赠送规则保留；新价不改旧账。
