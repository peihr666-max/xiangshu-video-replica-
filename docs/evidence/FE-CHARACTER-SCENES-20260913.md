# FE-CHARACTER-SCENES-20260913 — 人物形象与场景任务体验

人物详情两个入口原来返回人物库列表；场景生成已完成但详情缓存不刷新；素材列表将合成图衍生的参考视角逐张列出。维护后管理入口定位当前人物（包括分页外的人物），生成入口在详情直接展开场景名称、场景描述、服装描述。后台任务恢复与生成表单共用一个组件，关闭表单或重新进入人物也能看到任务状态。

## 数据与生成方式

- 用户反馈的已生成场景有已发布版本、合成图和参考视角；是前端刷新缺口，不需要重新生成。
- 正常成功链路调用图片供应商一次，`output_count=1`，返回一张包含五个画面的合成图。本地再裁切/镜像得到七个参考视角。质量失败重试按原后端策略处理，因此不承诺所有失败场景始终只有一次请求。
- 素材列表/计数按五视图展示一套，默认正面全身图作封面（缺少时依次回退正面半身、正面近景、已有视角）；展开可选择单图或完整合成图。首尾帧、原画面和下载使用当前选中的资产 ID；原图和所有视角均保留。已有裁切视角 ID 仍可解析供旧草稿使用；没有合成图的历史资产继续可见。隐藏一套不会让七个衍生图重新出现。合成图不作为单张首尾帧。
- 人物详情保留正脸图片作为口播/置换输入，展示时使用五视图合成图。仅有合成图时仍展示，但禁用需要单张人像的动作。

## 页面调整与边界

宽屏下基础图与场景照并列，窄屏上下排列；合成图完整显示，可放大查看。预先保留图片比例、稳定滚动条占位；定位字段改为多行输入和纵向拖动展开。独立浏览器审核预览观察到滚动后的布局稳定；未将截图证据等同于所有显卡/窗口尺寸下消除闪动。

生成状态读取失败时禁止重复提交并提供刷新；结果不确定时不发起第二次生成；共享轮询向多个订阅者广播进度，切换人物后忽略旧响应。详情刷新使用当前人物数据，不因场景完成而整页清空。

爆款卡片统一 9:16 封面、两行标题、三行标签占位；操作区在底部，两列详情/收藏与整行复刻对齐。完整标签仍可在详情查看，缺图和无标签也不会改变操作位置。独立审核预览首组六张卡片测得高度均为 659.125px，标签区 74px；两排操作相对卡片顶端约 553.125px / 603.725px（不同窗口下绝对值随卡片宽度变化）。
