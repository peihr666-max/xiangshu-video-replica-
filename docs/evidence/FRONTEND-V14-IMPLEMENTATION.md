## 范围与清理计划

用户已要求按完整 V1.4 总稿实现前端并逐页浏览器复核。本轮是独立的前端改版工作包，不更改客户 V3 已有任务的验收等级。原审核图册与全部旧版本保留，不把 PNG 作为页面实现。

1. 先锁定导航、草稿交接、防串人、条件输入与未接通能力的回归测试。
2. 新建统一的 `client/src/studio/` 页面层；复用现有 API、上传、分镜工作区、人物制作、生成批次、任务下载及账户组件，不复制认证/计费/Worker 状态机。
3. 工作台、爆款列表/详情、文案工坊、四类视频创作、任务中心/详情、人物库/四个详情页签、素材库、发布、统计、用户档案共16页21状态，共享导航与资产选择器。
4. 客户和内部工作区切入新页面层；成熟的复刻编辑与账户操作以同壳业务面板复用，旧入口保留回滚能力。
5. 逐页浏览器复核1600级桌面布局与小笔记本布局；修复结构、文字、间距、比例、交接和无效操作，再做全仓唯一一次收尾门禁。

## 视觉与交互基线

唯一设计正本：`前端页面V1.4-完整审核包-2026-09-05/`。黑色背景约#080909，面板#101111，细边框#292a27，暖金#e5aa36，正文#ecece8，弱文字#999b95。桌面左栏约288–300px，正文左右24–36px，表单/预览按各页原图比例分栏；大标题28–32px，正文16–18px，圆角8–12px。统一图标与人物ID消除生成图中的细微不一致。

开发审核入口仅开发环境可用，明确标记“示例审核，不调用业务接口”；使用相同生产页面组件和显式夹具，不能用接口失败自动降级为示例。正式工作区不显示演示的李总/张工/统计或假成功结果。

文案终稿+同IP声音+分身→文案口播；完整音频+分身→音频口播。两模式保留各自输入，提交仅取有效字段。人物照片只填目标参考，五视图合成图禁止用作单人分身照片。选用资产只修改当前草稿字段，不收费。任务结果到发布只形成草稿。所有未接通操作如实说明，不模拟真实成功。
