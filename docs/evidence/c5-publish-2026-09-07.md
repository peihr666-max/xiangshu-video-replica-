## 交付范围

把 C5 发布能力从"前端壳 + 全禁用"推进为代码闭环：

- **发布账号**：连接（粘贴平台 Cookie；抖音另需 security_sdk 材料）、异步登录态校验（verify_requested → publish_worker 探测 → connected/invalid）、删除。凭据一律 Fernet 加密落库（`VIDEO_REPLICA_SETTINGS_KEY` 体系），API 响应与日志永不回传凭据明文（红线测试锁定）。
- **发布记录**：草稿云端持久化（替换原会话内存草稿）、入队发布、状态机 draft → queued → publishing → published/failed/canceled、平台作品 ID / 短链 / 失败原因回传、失败重试（上限 3 次）、排队取消、定时发布（`schedule_at`）。
- **封面**：自动抽帧（默认）/ 素材库选图 / 上传图片（走素材三步通道入素材库）三来源；`cover_asset_id` 指向素材库 image 资产。
- **统计**：`GET /api/studio/stats` 新增真实 `published_total`（首页"累计已发布"接真数，替换恒 `—`）。
- **执行**：独立 `publish_worker` 进程（`npm run dev:publish-worker`），复用 CAS 租约 claim/prepare/perform/finalize 模式；同账号串行（一次只跑一个发布）、过期租约隔离、发布失败联动账号 invalid。
- **供应商引入**：`server/app/publishers/vendor/` 下协议级发布器（douyin_publisher / weixinshipinhao_publisher，所有者自有仓库），清洗改造与安全事件记录见 `server/app/publishers/vendor/*/VENDOR-NOTES.md`。
