## 实现与边界

1. 选择有效图片并点击生成后、任何上传请求之前显示“人物图像使用授权”；展示本次文件名、人物名、授权范围、服务处理说明和上传责任条款。
2. 勾选框默认关闭；取消、关闭或更换图片后重新生成均需确认。确认前不创建任务、不上传、不扣费。确认的文件快照用于提交，重复点击有同步锁。
3. 全局及项目范围异步上传接口拒绝缺失确认或过期版本，返回 422 / IMAGE_AUTHORIZATION_REQUIRED。检查先于文件读取及存储、任务和计费。旧同步入口仍不可调用。
4. 授权版本、确认状态和用途进入任务请求；任务自身的创建者、服务器时间、源图 SHA256 绑定授权。审计 action 为 simple_character.image_authorization.accept，与任务一起提交；幂等重放不重复审计。
5. 文案使用“依法承担相应责任”，不宣称平台可免除全部法定义务。图像多视图授权不替代声音克隆和数字人分身授权；勾选声明是用户确认记录，不是权属真实性验证。

不新增数据库迁移。前后端应一起发布；旧客户端缺少声明字段将被明确拒绝，不提供绕过开关。OpenAPI 类型仅同步本次两个上传表单字段，避免混入已有生成文件的无关漂移。
