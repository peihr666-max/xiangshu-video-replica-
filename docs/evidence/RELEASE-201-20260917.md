# 2.0.1 服务端与桌面升级

用户授权将当前主线服务部署到既有宝塔服务器，并生成可覆盖旧版的桌面安装包。代码基线为 `58e147dc`（含 #126–#131 已合并成果），发布分支仅统一版本为 2.0.1，不调整应用标识、产品名称、可执行文件名称或 NSIS currentUser 安装模式。

## 升级合同

- 原版本：2.0.0；目标：2.0.1，版本递增，`allowDowngrades=false` 保持。
- 标识：`com.xiangshu.video-replica.customer`，凭据命名空间保持。
- 产品：短视频复刻客户云工作台，NSIS 通过既有注册项识别安装目录；保留用户自定义路径。
- 本轮不修改卸载/旧版迁移钩子，不清除本机应用数据。
- 签名渠道与实际安装结果记录在最终交付清单；没有证书时不将未签名包冒称正式签名发行。
