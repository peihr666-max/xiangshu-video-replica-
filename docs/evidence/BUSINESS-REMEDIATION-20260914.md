- 本地上传和签名媒体 URL 改为相对 API 路径，由客户端按自身 API 基址解析。经客户 API 代理上传会携带本次用户凭证；第三方预签名上传不带业务 Authorization。没有取消资产归属、签名和会话校验。

- Hifly 兼容真实顶层响应和既有 `data` 包装；余额读取 `left`，照片参数 `image_url`、整数 `aigc_flag`、分身任务返回 `avatar`，上传票据和列表分别按端点验证。依据[供应商官方文档](https://api.hifly.cc/hifly.html)及真实分身、声音、口播成功响应。
- Windows 上传声音探测原来持有 `NamedTemporaryFile`，ffprobe 无法重新读取，合法 MP3 被误判 422。改成关闭文件后探测；同一个 24.085 秒 MP3 修复前失败、修复后真实上传成功。
- 同账号资料定时刷新产生新对象，原先会重建工作区素材，导致场景选择失效和正在播放的成片消失。稳定身份依赖；显式完整刷新仍重新加载人物素材。
- 下载授权原来按账号猜测唯一活跃会话，重新登录时新旧租约重叠会返回 401。下载授权改用本次请求经过事务验证的会话，保留会话撤销后的签名失效能力。
- 本地素材不满足云分析 HTTPS 前置时，手动分析在任务/扣费前拒绝；上传自动分析也检查同一前置，上传本身仍成功。错误提示明确指出存储准备事项，不伪装成素材库错误。
- 业务刷新及任务轮询同步钱包。个人中心新增人物图片、首帧、分析、二创、ASR、链接解析、分身、声音与采集筛选。
- 管理流水统一积分单位，补充业务名称、来源任务和计费操作关联；管理图片记录读取实际结算与调用尝试，重试不重复累乘消费，任何未知调用成本都会保留未知。配置价格估算不宣称供应商账单。
- 声音卡片允许换行，修复真人操作中试听控件与确认按钮溢出。上传提示不再把本地文件误称为已上传云存储。
