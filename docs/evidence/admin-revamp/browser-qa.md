# 管理后台改版浏览器验收（2026-09-05）

## 验收范围和方法

本轮依据 `docs/design/admin-redesign/work-plan.md` v2 和最终业务裁决，完成 W3–W17 实现及浏览器对照。预览为本机 `http://127.0.0.1:5174/admin`，API 使用隔离本地数据库；未连接生产、真实支付或付费 Provider。

后台参考图为 `native-style-v4/v01–v12`，按 1536 × 1024 桌面尺寸，将参考图和实际浏览器截图放在同一比较输入中逐页检查。检查包括层级、字体、间距、黑金配色、表格密度、状态、单位及可见操作。先记录差异，再修改和重新截图。原始迭代裁决保存在 `.omx/state/admin-revamp/ralph-progress.json`。

**结论边界：完成已裁决范围内的视觉与交互复核，不宣称逐像素相同。** 实际数据条数、租约有效期、历史未知成本和余额与效果图的示例数据不同；保留已定稿品牌和现有客户端工作台结构。未恢复被业务裁决排除的批次、发放记录、生成设备归属或按实际输出秒数扣款。
