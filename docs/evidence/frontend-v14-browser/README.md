# V1.4 前端浏览器复核

核验日期：2026-09-05 至 2026-09-06。分支：`codex/frontend-v1.4`。此记录仅覆盖前端改版，不能替代真实供应商/Windows安装包/客户UAT验收。

## 审核方式与结果

- 以项目根目录 `前端页面V1.4-完整审核包-2026-09-05/` 为设计正本，保留所有旧图。
- 浏览器直接运行 React 组件，不用整张效果图充当页面。所有21状态已截图并人工逐页查看，修复重复操作、图像裁切、按钮出屏、错误交接等问题。
- 1586×992 与1366×768各检查21状态：文档宽度等于视口宽度，正文滚动宽度等于正文宽度，无横向溢出；图片损坏计数0；审核浏览器控制台 warn/error 0条。
- 小窗口采用纵向滚动，不强制把所有内容缩到一屏。主导航/表单可操作，不代表手机适配或无障碍全项验收。
- 本轮主色、模块顺序、分栏和操作层级对齐正本；人物/建筑图片为独立重建，图标与文本做了可读性统一，未声称像素级一致。真实空态、禁用提示、原业务面板样式是有意保留的能力边界。
- 五视图按一张合成图完整展示。原生成素材不是严格的五个正交角度规范，正式人物资产仍以用户上传/生成确认结果为准。

## 浏览器实际联动复核

1. 文案工坊“用于数字人口播”带入终稿V3、张工IP、同人物声音和分身；口播不出现第二个文案编辑器。
2. 场景照片选“张工工地巡检”用于人物置换：目标参考变成construction，原始画面仍为li；旧预览失效，确认按钮禁用，未伪造新结果。
3. 口播→管理声音：试听不会跳转/修改草稿，无样本时明确提示；“使用此声音”独立负责带回口播。
4. 张工切换李总：旧声音、分身和文案确认失效，生成按钮禁用，提示核对自我介绍。终稿标识改为待确认。
5. 任务结果→发布管理：只创建发布草稿；编辑标题、添加“庭院设计”标签、保存、进入素材库再返回，标题与标签仍保留。刷新/关闭应用后的云端持久化尚未接通，界面明确为当前会话草稿。
6. 开发示例不会真实提交或扣费；正式失败不回退到张工/李总示例。此隔离另有自动化测试覆盖。

## 自动化与安全证据

- 全仓门禁 `npm run check` 通过一次：前端当时767项、服务端1556项（PostgreSQL fixture启用，432.82秒），Tauri cargo fmt/check、Ruff/mypy、E2E静态检查通过。
- 视觉和联动修复后再次运行前端 `npm --workspace client run check`：69文件、796测试通过，Biome157文件、TypeScript通过。最终小修另做复验，见主实施记录。
- 测试发现后修复：过期来源回退、关闭工作区重复导入、交接批次未清空、发布标签丢失、试听误当选择、跨人物终稿标记错误；先出现失败测试，再修复。
- 无新依赖、无数据库迁移、无真实密钥新增；运行项目秘密扫描通过。依赖漏洞扫描、Windows NSIS构建与桌面运行验收按项目规则保留为CI/发布阶段门禁，本轮未执行。
- 已有非失败警告：jsdom的scrollTo未实现提示、Rust两个macOS未使用常量、Starlette测试客户端httpx弃用提示。不把它们称为零警告全平台构建。
