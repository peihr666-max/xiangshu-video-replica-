## 实现

### 字号与导航

迁移 579 处固定字号声明至统一 typography.css，详见 [字号盘点](UI-TYPOGRAPHY-BRAND-20260916-font-inventory.md)。页面标题 24px，分区 18px，次级标题 16px，正文/输入/导航 14px，辅助文字 12–13px，数据 28px。侧栏宽 224px，头像入口只显示用户名；积分仍保留在账户页。任务中心移除右上角视频复刻快捷按钮。

### 文案工坊

来源原文 → 二创方式与参数 → 生成结果编辑 → 确认终稿。原文来自视频提取，提取完成不冒充生成结果；历史明确保存的文案即使与原文相同仍可编辑。原文和结果文本框支持右下角纵向拖拽。

- 按人物 IP：人物定位、受众、风格、真实资料与表达边界，加本次补充要求。
- 按要求二创：无需人物，直接输入改写要求；两种方式调用同一 DeepSeek 接口。
- 文案字数：接近原文 / 约100、200、300字 / 自定义1–5000整数。空值、负数、小数、超限值禁止提交；草稿恢复使用同样校验。字数进入实际 instructions，生成结果展示实际字数，页面说明是近似目标。
- 服务端输出上限从2048提高到8192 tokens，socket等待从120提高到240秒，保留五分钟任务租约余量。截断结果明确报错，不保存为完整稿。未进行真实5000字付费生成验收。
- 异步结果核对账号、来源、原文、方法、要求及人物档案。生成期间人工改稿保留，AI结果转候选；候选携带scopeKey防跨范围应用。已受理任务按任务ID恢复；未知是否受理且无任务ID时禁止从历史latest自动覆盖，重试沿用幂等键。确定提交失败清除pending。

### 人物 IP 内容

长期档案包含：姓名、职业角色、服务领域、目标受众、受众问题、表达风格、真实经历与业务资料、代表文案、禁用表达/不可承诺事项。新增四字段持久化在已有persona JSON中，旧客户端省略字段时保留原值；保存及二创快照均保持所有权检查。风格样本只用于学习表达，不当作本人事实经历。

### DeepSeek 范围

现有二创链路已接通两种方法。统一文本请求函数支持 rewrite / analysis / title / prompt，用同一DeepSeek配置与传输；设置页改为“文本 AI · DeepSeek”。这不代表新增了三种独立用户功能入口。视觉视频分析仍需视觉供应商，音视频生成保持既有通道。

### 品牌图标

按用户最后提供的金色纯图形重绘透明 SVG，去除背景和文字，衍生浏览器 PNG/ICO 与桌面多尺寸图标。前台、管理端HTML及静态构建复制规则均更新。源图很小，本次矢量重绘并非逐像素复刻。已安装客户端需重新构建安装包后更新。

## 预计费用“4秒”原因

草稿初始duration=8，复刻页normalizeCustomerDuration将≤9的旧值转成4，实际报价与提交均使用4秒。因此不是视频原时长或分析耗时。

已在复刻页显示“单条生成时长”4/15秒与生成数量，报价明确写成单价×秒/条×条数；旧8秒值显示按4秒处理提示。保留报价过期检查及服务端结算规则。未擅自改变其他视频创作默认时长、供应商档位或计费单价。0积分原因需根据后台价格配置确认，不能由截图判定免费。
