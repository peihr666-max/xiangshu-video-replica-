## 架构与安全

React/TypeScript/Tauri 客户端和独立后台共用 FastAPI/PostgreSQL 业务真源。钱包按 user_id 归属，Token 只是认证凭据，更新凭据保留逻辑分组和历史消费。后端确定目标账号与价格，客户端不能用传入余额或 Token 标签改变计账归属。

管理员写操作经过 Cookie 认证、CSRF、原因确认、幂等和审计。支付核验在数据库事务外请求网关，返回后重验管理员权限，并按原订单统一结算。历史转换使用钱包锁、策略版本、预期余额和一次性记录，追加差额账本；不改写历史交易。

本批原生账号订单/流水接口已修复旧代理缺配置导致的详情失败。全局历史管理接口仍有既有部署依赖，本报告不将未测全局经营分析、供应商配置等页面列为通过。
