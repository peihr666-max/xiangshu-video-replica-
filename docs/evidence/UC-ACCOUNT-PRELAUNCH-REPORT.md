## 架构与安全

React/TypeScript/Tauri 客户端，独立管理端，FastAPI 与真实 PostgreSQL 同一业务真源。钱包以 user_id 为账户主键；Token 仅是认证凭据，后端确定归属并在任务/流水保存凭据和价格快照。更新 Token 不迁移钱包，也不抹除旧消费。

后台写入口使用管理员 Cookie、CSRF、原因和确认、幂等键与审计；网络重试保留同一请求键。补发先在短事务外查支付网关，返回后重验管理员权限并走原订单统一结算。客户接口不接受管理员指定的价格或余额，不泄露密钥摘要、密码哈希、内部审批单号和原因。

历史余额转换使用策略版本和钱包预期余额检查、行锁及一次性转换记录；差额新增 CONVERSION 流水，不改写原交易。已存在转换/补偿数据时禁止破坏性回滚。新迁移、head 常量、结构指纹及离线兼容清单已经同步。
