## 账号与凭据边界

- 每个产品用户使用按原始字节编码的目录（避免 Windows 大小写路径混同），每个平台账号使用 UUID 独立 WebView2 数据目录。账号元数据仅含平台、UID、用户名、验证时间，Cookie/站点存储由 WebView2 留在本机。
- 原生账号命令检查本机 main 窗口与可信 origin；官方窗口不增加远程 IPC capability。页面注入脚本限制顶层、三个精确 origin 与本人账号接口，其他响应不克隆、不回传。
- 添加、重复账号、取消、超时、窗口关闭、账号不匹配均有明确状态；重新登录发现不同 UID 时清除本次资料，不能静默改绑。解绑使用 Windows ClearBrowsingDataAll 完成回调，失败保留记录，不以请求受理冒充清理成功。
- 退出产品登录及关闭主窗口时关闭官方窗口；保留正常已连接账号的本机登录目录供下次使用。
- 旧阶段服务端 Cookie 接口保留兼容，已有旧凭据不会自动下载、迁移或删除。新 UI 使用本机扫码链路；旧账号需要在本机重新扫码。未宣称历史服务端凭据已全部清除。
- WebView2 用户目录的语义参见 [Microsoft 用户数据目录](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/user-data-folder)。脚本执行范围参见 [Tauri WebviewWindowBuilder](https://docs.rs/tauri/2.11.5/tauri/webview/struct.WebviewWindowBuilder.html)。Windows 完成回调复用锁定的 webview2-com 0.38.2 / windows-core 0.61.2，Cargo.lock 仅新增主包的直接依赖关系，没有更新第三方版本。
