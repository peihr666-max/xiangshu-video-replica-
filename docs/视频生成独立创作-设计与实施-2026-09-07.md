## 二、后端

### 通道与端点
- `POST /api/independent/video-tasks`（幂等建批）：mode(t2v/i2v/r2v) + prompt_text + 帧/参考资产 + 参数 + idempotency_key。批次落 `generation_batches`（project_id NULL、creation_kind='independent'），prompt_text+参数冻结进 request/prompt snapshot，不走 LOCKED prompt 版本链；逐任务按秒 `reserve_internal_billing`；同事务 `ensure_user_queue_cursor`。
- `GET /api/independent/capabilities`：i2v 恒开放；t2v/r2v/last_frame 取决于总开关；附 max_quantity。
- `GET /api/studio/saved-prompts`：跨项目聚合 `versions(kind='saved_prompt', author_user_id=actor)`，只读（存储复用迁移 061，零新表）。
- 列表/详情/取消/预览/下载/重试/对账：**零新建**，全部复用既有 generation 端点。

### 迁移（075_independent_creation）
- `generation_batches.project_id` → nullable；`(created_by_user_id, created_at) WHERE project_id IS NULL` 列表索引。
- `uq_generation_batches_independent_idempotency (created_by_user_id, idempotency_key) WHERE project_id IS NULL` 部分唯一索引——NULL project 在 SQL 唯一约束下互不相等，必须由它兜底幂等。
- `runtime_settings.h3_extended_modes_enabled`（默认 FALSE）。
- 重建 `ck_wallet_transactions_shape` 为 057 按秒放宽语义（兼容 oral ±1 与 generation -seconds/+seconds 两套流水）。

### H3 协议扩展（generation.py）
- `build_h3_request`：按输入自动分流——T2V（仅 text）/ I2V（text+first_frame，可选 last_frame）/ R2V（text+reference_image 对象，name 必填）。既有 I2V 复刻流签名与输出逐字段不变。
- `validate_h3_request`：显式模式判定 + 互斥校验（R2V 不得携带首尾帧）；HTTPS 强校验保持在 metaso 提交路径（`_h3_request_has_https_first_frame` 泛化为"所有图元素须 HTTPS，纯文本通过"）。
- worker 直接提交路径与 `prepare_generation_submission`：按 lease snapshot 逐图签名（15 分钟直链），复刻流（快照无新键）零行为变化。

### 生产守卫（与复刻流同源）
- 客户生产禁止 fake_h3（503 FAKE_H3_PROVIDER_FORBIDDEN）；metaso 提交前预检配置 + acceptance 限额；仅作用于新提交，幂等回放先于这些检查返回。

### 批次访问（require_batch_access）
- `str(NULL project_id)` 会让复用端点系统性 404。新增统一助手：项目批走项目 ACL；独立批仅创建者与 admin（否则 404）。已覆盖：详情、列表（WHERE 子句）、取消、隐藏、重试、重生成（批/任务两级）、预览 URL、对账（提交/读取/最新）。

## 三、前端

- `api.ts`：`getIndependentCapabilities` / `createIndependentVideoTask` / `listUserSavedPrompts`；`GenerationPriceQuote` 时长/条数放宽为 number（服务端同步支持 4–15 秒任意档位）。
- `live.ts`：`loadVideoMaterials`（素材库图片 → 签名 StudioAsset，并入 `data.materials`）；`uploadVideoMaterial`（素材三步上传，就地进度）。
- `VideoPage`：提示词区「导入提示词」（我的提示词列表一键回填）；首帧/尾帧/参考素材均提供「本机上传 + 从素材库选择」双通道；**预览区进度视图**——阶段时间线（已提交→排队中→生成中→完成）+ `<progress>` 百分比 + 已等待（UTC 解析补 Z）+ 6 秒轮换安抚文案 + 失败不扣费指引；提交后留在本页，批次进度经 20 秒任务轮询驱动。
- `StudioWorkspace`：视频生成分支的准入校验（mode 推导、能力门禁、素材存在性）；确认弹窗视频分支（按秒报价 effect + 防抖 + 费用行 + 摘要）；`submitVideoTask`（crypto.randomUUID 幂等键，成功后 `patchDraft({videoBatchId})` 就地进入进度视图）。
