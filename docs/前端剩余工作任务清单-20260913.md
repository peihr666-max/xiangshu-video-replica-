# 前端剩余工作任务清单

依据本轮对话、前端审计和 main 已合入的 PR #93、#95、#97、#98 整理。以下编号用于后续排程，不替代 CW 业务账本，也不表示已经认领。代码完成、自动测试通过、真实业务验收与生产上线分别记录。

本次 FE-VIRAL-ACTIONS 将爆款列表、收藏卡片和首页精选的主操作统一为「查看详情 / 提取文案」，移除详情页「视频复刻」，列表收藏改为封面图标。额外修复文案提取上下文忽略新导入项目/素材参数、误取旧草稿来源的问题。通用创作工作台的上传复刻入口继续保留。
