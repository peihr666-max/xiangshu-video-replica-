# 如何审核本次爆款视频用户端效果图

打开同级的“00-打开审核.html”，或访问提供的本地审核链接。

1. 点击“从抖音列表开始审核”或任意缩略图查看大图。
2. 用左右箭头切换 17A、17B、17C；Esc 关闭。
3. 在每张图下方填写“通过 / 需调整”及文字意见。
4. 离开前点击“导出审核意见”保存 Markdown 文件。

本专项使用独立的浏览器存储键，不读写原 V1.2 图册的意见。同一浏览器、同一地址才会读取同一份记录；更换端口或浏览器请先导出。

审核重点：前端是否足够简单；两个平台是否分开显示；内容卡片和视频详情是否清楚。所有采集设置、API 参数和云端运维都在后台，不出现在用户页面。
