## Phase 1 后端独立创作通道
1. **迁移 074_independent_batches**：`generation_batches.project_id` 改 nullable（013 先例）+ `(created_by_user_id, created_at)` 索引 + `runtime_settings` 增 `h3_extended_modes_enabled`（默认 false，扩展模式真实提交的总开关）。
2. **新文件 `server/app/independent.py` + `independent_routes.py`**（照 oral_routes 骨架）：
   - `POST /api/independent/video-tasks`：mode(t2v/i2v/r2v)+prompt_text+帧/参考资产 id+resolution/duration/ratio/quantity+幂等键；门禁=require_not_auditor、`require_asset_access`、图片 kind/COS 校验；直接写 `generation_batches`（project_id=NULL，prompt_text+参数进 request_snapshot_json，不走 LOCKED prompt 版本链）、`creation_kind="independent"`、逐任务按秒 `reserve_internal_billing`、`ensure_user_queue_cursor`；幂等用批次表既有 UNIQUE(user, idempotency_key)；扩展模式受 074 开关门禁（关闭→409 `EXTENDED_MODE_PENDING_VERIFICATION`）。
   - `GET /api/independent/capabilities`：返回各模式可用性（i2v 恒真；其余=开关态），驱动前端 UI。
   - 列表/详情/取消/预览/下载：**零新建**——批次进现有 `listGenerationBatches` 即被任务中心/预览/对账全链覆盖（`list_generation_batches` 补 NULL project 按 created_by_user_id 过滤的分支）。
3. **H3 请求扩展（generation.py）**：`build_h3_request`/`validate_h3_request` 按模式分支——t2v（仅 text）、i2v（text+first_frame[+last_frame]）、r2v（text+reference_image 对象编排）；复刻流现有 I2V 契约与测试保持不变；`prepare_generation_submission` 按 task mode 取帧 URL（尾帧/参考图同走 storage 签名直链）。协议形态以仓库 `docs/短视频复刻桌面端开发说明.md` §21 为准。
4. **提示词导入读端点**：`GET /api/studio/saved-prompts`——跨项目聚合 `versions(kind='saved_prompt', author_user_id=actor)`（只读，复用 061 存储，零新表）。
5. **测试**：新 `test_independent_creation.py`（照 test_oral_domain 模式：FakeH3Provider + 打桩 storage + worker 步进）覆盖三模式校验、幂等回放/409、RESERVE/SETTLE/RELEASE 全轮、扩展模式开关、creation_kind=independent 序列化、供应商名红线；`build_h3_request` 新模式向量测试。

## Phase 2 前端接线（studio VideoPage）
1. **api.ts**：`createIndependentVideoTask`、`getIndependentCapabilities`、`listUserSavedPrompts`（materials 三步上传/listMaterials/resolveMaterials 均已存在）。
2. **live.ts**：`submitIndependentVideo` 门面、`loadMaterials`（素材库进选择器）、`loadSavedPrompts`；任务轮询零改动（独立批次自动并入）。
3. **state.ts**：`buildVideoInput`（文图生页签：有首帧=i2v/无=t2v；参考生页签=r2v≥1 张；prompt 必填校验）。
4. **CreationPages.tsx VideoPage**：
   - 提示词区加"导入提示词"→ StudioDialog 列 saved-prompts（点击回填 prompt）；
   - 首帧/尾帧/参考素材各给"上传"（materials 三步+进度文案，照 PeoplePages uploadOralSource 模式）与"从素材库导入"（openPicker 扩展 sources）双通道；
   - **预览区改造**：提交前=现有素材预览；提交后=进度视图（阶段时间线 已提交→排队中→生成中→归档→完成 + `<progress>` 百分比 + 已用时/预计 + PHASE_MESSAGES 式轮播安抚文案），聚焦 5s 轮询该批次（页面隐藏暂停），完成后就地预览/跳任务中心，失败给重试指引——不再跳走页面。
5. **StudioWorkspace.tsx**：requestGeneration 加"视频生成"分支（buildVideoInput 校验）；确认弹窗加视频分支（报价 effect 按 duration/resolution/quantity + 防抖、费用行、模式摘要）；提交函数（crypto.randomUUID 幂等键）成功后**留在本页进入进度视图**；扩展模式被门禁时显示"待供应商核对"文案。
6. **测试**：StudioWorkspace.test.tsx 沿 vi.hoisted live-mock 模式新增用例组：导入提示词、上传/素材库导入、报价展示、三模式校验门禁、提交→进度轮询（fake timers）、扩展模式文案。
