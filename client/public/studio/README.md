# V1.4 界面示例图片

`brand.png` 使用用户提供的“众墅之家”原始品牌标识；页面通过样式转为金色，没有重复绘制品牌文字。

其余 PNG 是本次界面实施使用内置图像生成工具生成的独立人物/乡墅示意素材，不是页面大图切片，也不是真实客户的数字人或生成成片。人物形象、建筑照片用于保持乡墅行业场景一致；`five-views.png` 为一张合成图，展示时必须 `object-fit: contain`，禁止裁成五个文件或作为单人分身照片。

图片通过开发专用 `fixtures.ts` 引用；正式人物、项目和成片使用认证后的服务端资产。生成预览中的音频波形/视频封面只是审核示意，无可播放URL时不声称已试听或已生成视频。
