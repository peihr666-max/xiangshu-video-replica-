> 飞影专项更新：本文件的“四项输入”归纳的是现有文案流水线，不代表飞影官方能力上限。最新官方 API 已核实支持音频直接驱动和网感模板；口播页按“文案/音频”输入模式与“标准/模板”样式组织。以同目录“00-飞影数字人口播-API与页面设计.md”为本次口播专项设计依据；音频模式不要求声音和终稿，模板模式不叠加标准字幕参数。新能力仍需接入，不是已完成开发。

## 一、整合结论

采用“共享内容和资产、分开生成工具、统一任务与发布”的结构。

入口可以有多个，但同一个动作只有一个处理位置。同一资产在不同模块引用同一记录，不因跳转再次上传、复制或训练；原始素材与新生成的衍生产物仍需分别留档。

- 文案工坊回答“说什么”：提取、二创、编辑、保存终稿。
- 人物库回答“谁来说”：IP 定位、场景照片、数字人形象、声音档案。
- 视频创作回答“怎么做出来”：视频复刻、人物置换、视频生成、数字人口播各有明确输入和输出。
- 任务中心回答“做到哪里、结果是什么”：共享进度、失败处理、结果与复用配置。
- 发布管理回答“发到哪里”：只接收已完成的视频版本，另行确认发布。

数字人口播不是第二个文案工坊，也不是第二个人物库。它是把已有终稿、IP、声音和数字人形象组合起来的生成界面。

## 二、口播的四项输入：来源、维护、使用

| 生成需要什么 | 可以从哪里开始 | 唯一维护位置 | 口播页只做什么 |
|---|---|---|---|
| 口播文案终稿 | 爆款视频；首页粘贴链接/上传视频；素材库视频；手写文案；已有文案版本 | 文案工坊：转写、二创、IP 化改写、编辑与版本确认 | 带入指定终稿，显示标题、版本和正文；可更换，修改回文案工坊 |
| 人物 IP | 文案工坊当前 IP；人物卡片；已有创作草稿 | 人物库 → IP 定位 | 显示张工/李总、角色及选择入口；不再填写定位表 |
| 声音 | 当前 IP 默认声音；人物声音档案；原任务配置 | 人物库 → 声音档案 | 带入已就绪声音，试听或更换；不重复上传样本、克隆和训练确认 |
| 数字人形象 | 当前 IP 默认形象；人物库已准备形象；原任务配置；关联该形象的素材预览 | 人物库 → 数字人形象 | 选择可用形象并播放预览，例如“张工 · 设计室讲解”；不把任意 MP4 当成数字人 |

“人物库是主维护位置，素材库是媒体索引和复用入口”：声音样本、训练视频、预览视频可在素材库被检索，但修改人物绑定、默认声音或形象仍回人物库。普通音频文件不等于声音档案，普通视频文件不等于数字人形象。

同一个张工可以有“设计室讲解、工地巡检、庭院介绍”等多种外观素材。场景照片可以有多张；只有完成对应数字人准备、成为可用形象资产的场景，才进入口播形象选择器。不能因为照片存在就显示为“可口播”。

### 特别分清五种视频

| 视频类型 | 业务用途 | 在新口播界面中的处理 |
|---|---|---|
| 爆款/来源视频 | 学习选题、提取台词和拆解画面 | 提台词去文案工坊；拆画面去视频复刻，不再在口播页建一个上传和解析区 |
| 人物实拍/训练视频 | 准备数字人形象 | 去人物库准备；成功后带入形象资产，不直接传原始文件生成口播 |
| 数字人形象预览视频 | 帮助辨认人物、服装、场景和表现 | 选择的是它关联的数字人形象，不是重新上传预览文件 |
| 已生成的口播成片 | 下载、保存、发布或复用配置 | “复用配置”带入原文案/IP/声音/形象引用；成片本身不自动变成新的形象 |
| 乡墅建筑镜头/AI 生成片段 | 视频复刻、参考生成或后续剪辑 | 不放入口播的形象选择框；自由插入镜头属于另行验证的剪辑能力 |

因此，口播页原来模糊的“视频素材/口播视频”栏统一改为“数字人形象”，并标注“形象预览，非本次生成结果”。

## 三、六条主要业务链

### 1. 从爆款视频或上传视频制作口播

爆款视频 / 首页链接与上传 / 素材库视频 → 文案工坊 → 确认终稿 → 数字人口播 → 任务详情与结果 → 发布草稿。

- 首页保留链接和上传两个入口，选择“提取文案”后交给文案工坊的同一处理流程，不在首页展开另一套编辑器。
- 平台简介不是转写全文。已有同一来源的有效转写可以复用，不能每次跳转自动重复提取。
- 文案工坊按选定 IP 进行二创；终稿带入后，口播页不再解析、转写或自动改写。
- 从爆款页点击“做口播”时，若尚无终稿，目的地仍是文案工坊，不出现第二个口播导入页。

### 2. 从已有文案直接制作口播

文案工坊选中终稿 → 点击“生成数字人口播” → 同一个口播生成页。

自动携带文案 ID、确认版本、正文快照、IP 和来源。按该 IP 补入默认可用声音、形象。四项齐全时只核对后生成；缺哪项仅补哪项，不强制重新走全流程。

如果要修改哪怕一句文案，点击“去文案工坊修改”，保存为新版本并确认后回原口播草稿。口播页不提供另一套可编辑正文。

### 3. 从人物库开始制作口播

人物卡片 / 某个数字人形象 / 某个声音 → “用于数字人口播” → 同一个口播生成页。

先带入所选 IP 和资产。没有文案时显示“选择已有文案”与“去文案工坊准备”，不是在口播页重新搭建提取、写稿、二创工具。

补声音或形象也回对应人物页签；准备完成并明确选用后，返回原草稿。训练仍在进行时可以继续处理文案，不丢弃已有选择，也不假装资产可用。

### 4. 人物场景照用于人物置换

人物库 → 形象资料 → 选“张工 · 庭院讲解” → 人物置换 → 确认置换首帧 → 回复刻当前镜头，或进入文/图生视频。

- 目标人物场景照与原始画面是两个独立输入，不能放反。
- 从人物库开始时，只填目标人物参考；没有原始画面就等待选帧/上传，不自动生成。
- 五视图显示一张合成图，不让用户依次上传五张；多场景照片另列。
- 置换后产出的是待确认首帧，不把一张成功首帧冒充整段视频已置换。
- 从复刻某镜头进入时，只回填该镜头；去文/图生视频时只回填首帧，不覆盖其他参考素材。

### 5. AI 视频创作与口播的衔接

两条生成工具共享 IP、素材与结果，但不把不同种类的产物强行互当输入。

- 普通 AI 视频 → 提取文案：进入文案工坊。
- 人物场景图 → 数字人：先去人物库准备数字人形象；是否可用取决于实际接入能力，不能直接标就绪。
- 口播结果 → 视频复刻/参考生成：作为普通来源视频，并按目标工具支持的格式、时长等校验；不继承“可口播形象”的身份。
- AI 建筑镜头 + 数字人口播拼接成片：属于剪辑编排需求，本轮不伪装成现有“一键合成”能力，不为尚未验证的功能新增操作页。

### 6. 结果复用与发布

任何生成工具 → 同一个任务详情 → 下载 / 保存素材 / 复用配置 / 去发布管理。

- “复用配置”创建新草稿，引用原任务的文案版本和资产快照；不自动收费、不重新运行旧任务。
- 新建发布草稿带入结果 ID 与视频版本；点击进入不等于发布。
- 发布标题和描述与视频中说出的文案分开。修改发布描述不能反向修改口播终稿。
- 播放链接不等于已存云素材；保存成功后才显示已入库，链接失效需明确提示。

## 四、每个模块只保留一份职责

| 模块 | 保留的主操作 | 不再复制的操作 |
|---|---|---|
| 工作台 | 链接/上传快捷入口、任务摘要、继续草稿 | 不内嵌完整文案二创、人物管理或生成结果库 |
| 爆款视频 | 抖音/视频号内容筛选、预览、收藏、提文案/复刻入口 | 不显示关键词采集、API、云存储配置；平台切换不是两个页面 |
| 文案工坊 | 来源提取、人工编辑、IP 二创、终稿版本 | 不克隆人物、训练声音或生成视频 |
| 视频复刻 | 来源导入、分镜、当前镜头编辑与复刻 | 导入与编辑为同一工作区的空态/有素材状态；置换复用对应工具 |
| 人物置换 | 原始画面 + 目标人物场景，生成与确认首帧 | 不再建一套人物资料；空态/带入态不各建页面 |
| 视频生成 | 文/图生视频、参考生视频 | 文生与图生合为一个按钮；不做另一套人物和素材管理 |
| 数字人口播 | 终稿、IP、声音、数字人形象的选择核对与提交 | 无来源提取、二创、定位表、克隆训练、授权与状态板块 |
| 人物库 | IP 定位、形象资料、数字人形象、声音档案四页签 | 不在此做整套口播生成；“用于创作”只负责携带素材 |
| 素材库 | 媒体上传、分类、预览、选择用途 | 不另存一套 IP/声音/数字人资料；不复制文案编辑器 |
| 任务中心 | 统一进度、详情、失败处理、结果 | 各创作工具不再各建任务列表和成片结果页 |
| 发布管理 | 视频版本、平台账号、发布标题描述、确认发布 | 不修改口播终稿，不重新生成视频 |
| 数据看板 | 内容效果和趋势 | 不重复发布设置或任务操作台 |
| 用户档案 | 当前登录用户/账户设置 | 与张工、李总等“内容人物 IP”分开，不复制人物库 |

只读摘要、快捷入口、同一个选择器的重复使用不是重复业务界面；不同地方都能编辑同一内容、分别训练或生成，才是需要剔除的重复职责。

## 五、数字人口播页具体保留什么

页面标题“数字人口播”，属于视频创作第四个工具。不要显示文/图生视频、参考生视频的二级按钮。

- 左侧：口播文案只读预览，显示来源和终稿版本；轻操作“更换文案”“去文案工坊修改”。
- 右侧：一个已选数字人形象预览；下面两行展示“人物 IP”和“声音”，附更换/试听入口。
- 底部：一个“生成口播视频”主按钮。费用确认使用弹层，不新增确认页面；报价和提交由明确用户操作触发。
- 缺文案、声音或形象时，只在相应位置提示缺项并导航去准备，保留其他内容。
- 当前已核查生成接口没有可选语速字段，不照搬草图中的可调“语速”控件。字幕/封面微调统一放任务结果的同一编辑面板，使用已验证能力，不在生成页再复制一份编辑台。

不展示独立“授权与状态”页面或授权条件面板。必要的归属、可用性与权限检查保留在服务端；缺素材提示、训练中提示和任务进度不等于被删除的“授权与状态”模块。资产准备所需确认只在准备流程内完成。

## 六、跨模块交接必须遵守的规则

以下是目标交互合同，尚不能视为两个系统已经接通。

1. 带对象引用，不靠复制文本、临时播放 URL 或供应商 ID 建立业务关系。文案携带明确版本；人物、声音、数字人形象分别有自己的引用。
2. 跳转前保存当前草稿。保存失败不假装成功；补资产返回时恢复原文案、人物选择、页签和来源位置。
3. 从外部入口开始新创作，与“给当前草稿补一项素材”要区分。已有未完成草稿时不能静默覆盖，使用简短选择弹层确认去向，不新增业务页。
4. 同一 IP 内更换单项只更新对应位置；取消选择不改变原稿。返回后只有用户明确选用的就绪资产可以回填。声音和数字人形象选择器本版按当前 IP 过滤，不允许单独带入另一个 IP 的资产。
5. 更换 IP 时保留文案历史，但清理或重新确认旧声音、形象以及文案中的人物称谓。若从另一个 IP 的资产入口返回，必须先明确切换 IP，并同时更新身份和关联选择、重新确认文案及报价；取消则整组保留原选择。不能出现李总身份配张工形象的中间组合，不能只靠当前“用户归属”校验代替这一规则。
6. 更换文案版本、声音、形象或影响费用的配置后，旧生成确认与报价失效。不能用旧试听冒充新文案的合成音频。
7. 已提交任务使用冻结快照。后来改 IP 默认声音或文案，不回写历史任务。
8. 进入页面、选 IP、选素材、播放预览都不触发生成或收费。用户确认提交后才创建任务；受理不明确先核对，不盲目重提。
9. 已知失败在同一任务详情处理，按真实可恢复步骤续作；不因页面合并承诺所有情况下都可以无成本复用。
10. 资产过期、不可用或不属于当前用户时保留草稿，解释具体缺项；最终提交仍由服务端校验，不只靠按钮置灰。

## 九、下一轮界面与联动验收清单

下面是待执行验收，不代表已经通过前端或接口测试。

- 从爆款、首页、素材库提文案，都到同一个文案工坊；终稿进入口播后逐字一致、版本一致，不再次调用转写和改写。
- 从不同入口进入口播始终是一个页面；文案、IP、声音、形象各只显示一个当前选择，不嵌套整个资料库。
- 从口播去修改文案/补声音/准备形象，成功、取消和刷新后均不丢原稿；没有补齐时不能生成。
- 口播形象选择器拒绝普通 MP4、普通场景照、生成结果视频冒充 avatarId；声音选择器拒绝普通音频冒充 voiceId。
- 五视图只有一张合成图；多个场景照片各自对应正确人物；置换原始画面与目标参考不串位。
- 切 IP 后明确核对声音、形象、文案称谓；从其他 IP 的声音/形象入口返回也必须整组确认，不能单项回填串人。资产或终稿变更后旧报价不可提交。
- 文/图合并后不重复输入；首帧缺失时不保留生效的旧结束帧；有首帧时不显示“需先添加首帧”的错误提示。
- 同一任务只有一个详情/结果入口；只读任务动态仍可保留为摘要，不另建操作台。
- 进入发布管理只建草稿，修改发布描述不改变视频正文；保存云素材成功前不标已入库。
- 用户端没有采集设置或授权与状态页；必要后台检查没有随界面去重而删除。
- 全部图统一黑金品牌、侧栏顺序及乡墅角色案例；四个视频创作工具页签与视频生成内部模式不混层级。
