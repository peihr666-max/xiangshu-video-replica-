# 数字人口播：飞影 API 方案、参数来源与页面设计

日期：2026-09-05。范围：官方文档与本地代码对照、业务设计、单页效果图。未调用真实飞影账号、未创建付费任务、未修改正式业务代码。

官方依据：[飞影数字人 API V2](https://api.hifly.cc/hifly.html)。本轮网页抓取工具超时，已通过普通 HTTPS GET 成功读取同一官方页面及其参数表。参考代码：`/Users/honor.pei/Documents/oral-ip-agents-research/`。

本文件优先于上一轮“00-业务联动与唯一职责.md”中仅按现有流水线归纳的口播输入范围。上一轮“四项输入”只适用于文案驱动，不代表飞影官方没有音频驱动和网感模板。

## 1. 先分清：创建形象，与生成口播，不是同一件事

- 创建数字人形象：准备“谁出镜”。视频或图片用于创建形象，完成后取得可复用的 `avatar`。在人物库维护。
- 生成数字人口播：准备“这一次说什么”。已存在的 `avatar` 与文案/声音或已有音频组合，生成视频。在数字人口播页操作。
- “图片创建数字人”不是 MiniMax 的“图生视频”；它不能因此给口播页增加文/图生视频、参考生视频、首末帧和画幅模型参数。

### 1.1 数字人形象的两种创建方案，及一种复用方案

| 方案 | 官方接口 | 原材料与主要参数 | 产品入口 |
|---|---|---|---|
| 视频创建形象 | POST `/api/v2/hifly/avatar/create_by_video` | `title`；`video_url` 或 `file_id` 二选一；可选 `aigc_flag` | 人物库 → 数字人形象 → 视频创建；选本人物的实拍/训练视频或上传新视频 |
| 图片创建形象 | POST `/api/v2/hifly/avatar/create_by_image` | `title`；`image_url` 或 `file_id` 二选一；`model`，默认 2；可选 `aigc_flag` | 人物库 → 形象资料选场景照 → 用于创建数字人形象，回数字人形象页准备 |
| 选用公共形象 | GET `/api/v2/hifly/avatar/list` | `page`、`size`、`kind=2`，返回公共 `avatar` | 人物库中的公共形象选择入口；这是复用，不是克隆本人的形象 |

公共形象不能标成“张工本人克隆”；需要明确其身份与使用范围。当前代码没有面向用户的公共形象选用链路，不在效果图中冒充已有可选资产。

视频与图片创建都先返回 `task_id`，再用 GET `/api/v2/hifly/avatar/task` 查询；完成后得到 `avatar`。没有完成时只能保存准备中的资产，不能视作可生成口播的形象。

### 1.2 官方素材限制与参考项目限制要分开

| 原材料 | 飞影文档明示 | 参考项目或设计补充 |
|---|---|---|
| 视频形象素材 | MP4/MOV，H.264，500MB 以内，360p～4K，5 秒～30 分钟；URL 字符数不超过 500；相同 URL 视为同一数字人 | 参考项目当前限制 30 秒～3 分钟，并接受 HEVC；HEVC 与本轮官方文档不一致，需要另行验证/转码，不应宣传为官方保证支持 |
| 图片形象素材 | `image_url/file_id`；`model=1` 为视频 2.0，`model=2` 为视频 2.1 | 文档这一接口表未明确尺寸、大小和人脸数量门槛，不编造数值。产品建议选一张清晰单人场景照；五视图拼图不能直接当单张场景形象 |
| 声音克隆样本 | MP3/M4A/WAV，20MB 以内，5 秒～3 分钟 | 用本人的录音样本；不是每次生成的正文配音，也不是背景音乐 |
| 直接驱动口播的音频 | MP3/M4A/WAV 等，100MB 以内，5 秒～30 分钟 | 这是“本次要说的话”的完整音频；与声音克隆样本的限制和用途不同 |
| 文本驱动的正文 | 不超过 10000 字，不支持 HTML 标签 | 超限应阻止提交并提示修改，不静默截断终稿 |
| 创作作品名称 | 不超过 20 个字，默认未命名 | 从文案标题带入，并保留单独的作品名称字段 |

图片创建与口播/音频创作被文档明确标注消耗积分；未标注的接口不能反向推断为免费。用户端费用必须由本产品报价确认，不直接用飞影账户余额当用户钱包。

来源视频若包含本人语音，只有经过明确取样和音轨提取后，才可以产生声音训练样本；现成视频链接不能直接当作 `audio_url`。不在本次口播生成页增加又一套取样工具。

## 2. 飞影生成口播的三条接口路径

| 路径 | 官方接口 | 需要的材料 | 不需要的材料 |
|---|---|---|---|
| 文本驱动 | POST `/api/v2/hifly/video/create_by_tts` | `text + voice + avatar`，作品名称；可选字幕参数等 | 不需要上传本次音频，不重新上传训练视频 |
| 音频驱动 | POST `/api/v2/hifly/video/create_by_audio` | `audio_url/file_id + avatar`，作品名称；可选 `video_start_msec` | 不需要 `voice`，不要求终稿去重新生成一次声音 |
| 网感模板 | POST `/api/v2/hifly/video/create_by_template` | `text + voice + avatar + template`，作品名称 | 不需要单独再选择一套标准字幕参数；该接口未列出 `st_*` 或起始时间字段 |

网感模板基于文本驱动，负责带标题、字幕的成片样式。因此界面只用两个输入模式“文案驱动 / 音频驱动”；“标准口播 / 网感模板”放在文案模式下的样式选择里，不做第三套内容输入页。

飞影还提供 POST `/api/v2/hifly/audio/create_by_tts`，输入 `voice、text、title` 等得到音频。参考项目当前采用“先 TTS 产音频，再音频驱动数字人”，它与官方直接文本驱动都是可行接口编排，但前端不需要为两种内部编排重复做按钮。

一次任务只能明确选择一条执行路径：
- 标准文案模式：沿用“单独 TTS → 音频驱动”或切换到直接 `create_by_tts`，由后端策略决定；不能两条都提交。
- 音频模式：跳过 TTS，用已确认的音频驱动形象。
- 模板样式：调用模板创建接口；不要再额外叠加另一套字幕渲染导致重复烧录。

## 3. 参数和原材料到底从哪里来

| 参数/内容 | 本平台来源 | 服务端如何转换 | 用户在口播页看到什么 |
|---|---|---|---|
| `ipId` | 文案工坊选定的人物、人物库、原草稿 | 这是本地 IP 身份，不是飞影参数；用于选择默认声音和形象 | 张工 · 乡墅设计师，提供更换入口 |
| `text` | 文案工坊保存并确认的终稿；原始输入可来自爆款、链接、上传或手写 | 按 `scriptId + version` 读取快照，不重新提取或改写 | 只读正文、来源、终稿版本；更换或去文案工坊修改 |
| `voice` | 人物库 → 声音档案的就绪声音 | 本地 `voiceId` 校验后映射为供应商 `provider_voice_id` | 本人音色名称，试听、更换；只在文案模式显示 |
| `avatar` | 人物库 → 数字人形象的就绪资产 | 本地 `avatarId` 校验后映射为供应商 `provider_avatar_id` | 形象名称、预览及更换；两种驱动模式都需要 |
| `audio_url/file_id` | 用户录好的口播音频，或素材库已保存的配音/录音 | 上传到受控存储，校验归属、格式、时长后，按供应商上传协议获得 `file_id` 或提供可访问 URL | 音频模式下的选音频/上传、播放器、文件名、时长 |
| `title` | 文案标题，或音频创作时填写的作品名称 | 校验长度后提交 | 一个作品名称字段，不新增重复标题表单 |
| `template` | 管理后台配置并验证过的飞影模板映射 | 可读样式名映射到真实模板 ID；文档指向飞影个人中心查看 ID，未提供此页的模板目录接口 | 模板预览/名称；没有可用模板时不能提交模板任务，不让客户手填 ID |
| `st_show` | 标准文案模式的“添加字幕”选项 | 直接文本驱动时映射 `0/1`；沿用分阶段链路时映射统一合成配置 | 简单开关或“不添加/添加” |
| `st_font_name、st_font_size、st_primary_color、st_outline_color` | 统一字幕样式预设 | 转换成飞影实际字体和样式参数 | 用样式预设，不把原始字段列表铺在主页面 |
| `st_width、st_height、st_pos_x、st_pos_y` | 适配实际成片画幅的字幕布局 | 服务端结合画幅计算/校验，不盲用文档默认值 | 主页面不暴露像素坐标；如需调整，进入同一结果编辑面板 |
| `video_start_msec` | 用户在已选视频形象预览中指定的起点 | 秒转换为毫秒，仅供文档列出的文本/音频驱动路径使用 | 折叠高级选项“形象起始位置”；不是通用视频裁剪，也不是口播总时长 |
| `aigc_flag` | 管理后台统一标识策略 | 文档值 0 跟随账号设置、1 开启、2 关闭；产品不向客户提供随手去标识的开关 | 主页面不显示；产品侧保持适当 AI 标识 |
| `task_id、request_id` | 飞影响应 | 绑定本地任务，查询状态、排错和防重 | 客户看本地任务，不看供应商原始参数 |
| Token、回调、上传签名 | 服务端安全配置 | 仅后台调用 | 不出现在用户界面或可分享的 URL |

字幕样式有且只有一份有效配置。使用模板时不同时提交标准 `st_*` 控件；音频接口本身没有这些字幕参数，音频模式的字幕若要提供，应在后续合成/编辑统一处理，不能假装飞影音频创建接口支持。

### 声音档案单独维护的参数

官方 POST `/api/v2/hifly/voice/create` 使用：
- `title`：必填，不超过 20 字；
- `voice_type=8`：目前仅这一克隆类型；
- `audio_url/file_id` 二选一；
- `languages`：不填默认普通话。

GET `/voice/task` 完成后提供 `voice` 和 `demo_url`；GET `/voice/list` 可按 `kind=1` 查自己的声音、`kind=2` 查公共声音。

官方 POST `/voice/edit` 可以修改声音的 `rate`（0.5～2.0）、`volume`（0.1～2.0）、`pitch`（0.1～2.0），都是字符串参数。这是在编辑声音资产，不是每个视频任务的临时参数；口播页不直接用滑块修改共享音色。当前 HiFly TTS 实现也未把传入的 speed 写入请求。

### 场景不是飞影的背景切换参数

“张工 · 设计室讲解”和“张工 · 工地巡检”应是两条数字人形象资产，各有自己的 `avatar`。本地 `scene` 只是标签，不能把修改标签画成更换视频背景。

现有形象预览取的是原训练视频或原图片，不是飞影另行生成的预演结果。所以图上标“形象预览，非本次生成结果”，不展示虚假的本次成片。

## 5. 口播页怎样设计，才不重复操作

保留视频创作的四个兄弟工具：视频复刻 / 人物置换 / 视频生成 / 数字人口播。口播内容内部不出现任何文/图生视频、参考生视频、MiniMax/H3 分辨率、比例、首末帧或固定 4～15 秒参数。

### 文案驱动：本次效果图展示的默认状态

- 左上输入方式：“文案驱动 / 音频驱动”，默认文案。
- 左侧：作品名称、终稿只读预览、来源和版本；“更换文案”“去文案工坊修改”。
- 左下：已有声音、试听、更换；不复制声音克隆、参数编辑表。
- 右侧：人物 IP、一个已选形象的预览和来源；“更换形象”“去人物库准备形象”。
- 底部：成片样式“标准口播 / 网感模板”；标准模式可显示简洁字幕选择，模板模式换成实际模板选择。
- 单个主按钮：“生成口播视频”。先报价与确认，再创建；旁边只保留保存草稿。
- 没有一整块“授权与状态”，但服务端归属、使用权限、准备状态和收费确认继续保留。

### 音频驱动：同一个页面切换，不新建一页

- 文案预览区替换为“选择已有音频 / 上传音频”、音频播放器、文件名和时长。
- 隐藏声音选择与文案必填检查，因为音频已包含这次要说的话。
- 保留 IP、数字人形象、作品名称、保存草稿和生成按钮。
- 隐藏网感模板和飞影文本字幕控件；不能在音频接口请求中夹带文本模板参数。
- 如有字幕转写稿，它是音频的附属资料，不能改了文字却继续播放旧音频。更换音频后清理旧字幕匹配确认。

### 模板样式：不是第三套创建流程

复用同一文案、声音、IP 和形象，只增加一个模板选择器；模板缺失时在原位置提示，不转去另一套模板创作页面。模板 ID 和配置在后台。

## 6. 素材联动与防重复规则

1. 来源视频/爆款视频 → 文案工坊提取二创 → 终稿版本 → 口播文案模式。平台简介不能当转写全文。
2. 人物场景照片 → 人物库创建图片形象 → 就绪 `avatar` → 口播页。普通场景照不绕过创建阶段。
3. 人物训练视频 → 人物库创建视频形象 → 就绪 `avatar` → 口播页。原视频不反复上传克隆。
4. 本次口播录音/已有配音 → 素材库或受控上传 → 音频模式。它是驱动音频，不是声音克隆结果 `voice`。
5. 草稿跳转只带稳定资产引用和版本；取消不覆盖。模式切换保留两侧草稿内容，但只提交当前模式有效字段，旧报价失效。
6. 新 IP/形象/声音要相互核对。当前代码只检查同用户归属，不保证显式资产绑定同 IP；必须防止补资产回来形成静默串人。
7. 从口播修改文案或准备资产，返回同一草稿；缺项用原位置空态，不新增导入页、补声音页和确认页。
8. 发布管理只接收任务成片版本；不反向改口播正文。任务详情统一，不另建一套口播结果库。

## 7. 后台负责的事情

- Token、真实模板映射、模型默认值、AIGC 标识策略、请求签名/上传、任务轮询或回调。
- 上传先用 POST `/tool/create_upload_url` 获取 `upload_url、content_type、file_id`，再按返回类型 PUT 文件；不能把自有素材库 ID 直接当飞影 `file_id`。
