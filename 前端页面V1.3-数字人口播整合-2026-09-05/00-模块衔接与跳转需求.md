# 众墅之家｜AI 即创 · 模块衔接与跳转需求

版本：V1.3 设计审核稿。日期：2026-09-05。

本文件描述目标业务与交互合同，不代表当前路由、接口或数据库已经支持。28 张效果图用来审核关键页面和交接状态；图上的业务按钮不能真正生成或发布视频。

## 1. 业务整合原则

一个创作平台、同一份人物身份、两条生成流程：

- 画面创作：来源视频或图片 → 镜头/首帧 → 目标人物与场景（可选）→ 确认 → AI 视频。
- 数字人口播：来源视频或已有文案 → 终稿 → 人物 IP → 声音与可用口播形象 → 确认 → 配音/数字人/合成。
- 两条流程统一到任务中心与成片结果。进入发布管理只建立发布草稿，不自动发布。
- 任务中心可汇总已提交任务和待处理草稿，但必须标明类型；例如“李总·开工准备”声音待确认时属于未提交草稿，不能混称已收费的生成任务。
- 左侧维持九项导航；数字人口播放在视频创作第四标签，声音与口播形象放进人物详情。

每次跨模块跳转必须回答：从哪里来；带过去什么；到达后可做什么；返回时保留什么；哪些旧结果或确认失效。

## 2. 必须分清的业务对象

| 对象 | 含义 | 不能混用为 |
|---|---|---|
| 来源视频 | 用户上传或从爆款视频选择的参考作品 | 已确认口播终稿 |
| 视频简介 | 平台发布文本/视频描述 | 完整语音转写稿 |
| 原始画面 | 从来源视频选出的帧或独立上传图，承载要替换的人物 | 目标人物形象照 |
| 人物身份 | 张工、李总等同一人的身份、归属与授权 | 某套服装/某张场景照 |
| IP 定位 | 身份、受众、内容主张、表达习惯、禁用表达 | 外观提示词或供应商账号 |
| 基础五视图 | 一张包含五视角的完整拼合图 | 五个独立上传入口，或可口播模型 |
| 场景形象 | 同一人物在庭院、工地、设计室等场景的版本化形象资料 | 原始画面或已训练的口播模型 |
| 口播形象 | 可由音频驱动、状态可用的数字人资产 | 任意一张普通场景照片 |
| 声音档案 | 已授权、训练完成并试听确认的音色版本 | 普通配音文件或背景音 |
| 文案版本 | 保存后的正文版本；已确认终稿才能提交口播 | 随时自动变化的最新文本 |
| 创作草稿 | 本次来源、文案、人物、资产选择、返回上下文 | 已收费生成任务 |
| 生成任务 | 用户最终确认提交后创建的执行记录 | 草稿、发布任务 |
| 发布草稿 | 成片及平台账号、标题、描述、话题等待发布内容 | 已发布结果 |

## 3. 用户重点提出的两条交接

### A. 文案二创 → 数字人口播

对应审核图：08 → 20E → 20C → 20D → 12。

1. 文案工坊展示原文、IP 改写稿与版本状态。未保存正文不能被当作已确认终稿。
2. 用户确认并保存终稿 V3，点击“生成数字人口播”。
3. 打开或创建口播草稿，带入：来源引用、文案 ID/确认版本、正文快照、人物 IP、返回文案工坊的位置。
4. 20E 顶部显示“来自文案工坊 · 张工·建房预算 · 终稿V3”；正文与确认版本完全一致。
5. 不重新解析来源、不再转写、不自动再次二创；带入该 IP 当前可用的默认声音与默认口播形象。
6. 缺少 IP 时停留在选择人物；有 IP 但缺少声音/口播形象时停留在补资产状态。
7. 用户只需核对人物、场景、声音及字幕选项，再进入费用确认；跳转本身不扣费、不提交生成。
8. 在口播页编辑正文会保存为新版本，旧 V3 保留；当前版本需重新确认，旧报价失效。
9. 返回文案工坊时恢复原文案和版本，不跳到空白首页。取消选择资产返回同一个口播草稿。

草稿分支：未确认文案允许“继续编辑口播草稿”，到达20B仍标草稿，不得绕过终稿确认。

连续看图使用同一个“张工·建房预算V3”案例；08、20E、20C保持同一正文，20D展示其生成结果，12仅修改发布标题/描述，不修改已生成的视频内容。09与09A分别展示列表时点和失败恢复分支，不是一次同时发生的真实运行快照。

验收：从08带入20E后，正文逐字一致，IP相同，版本可追溯；进入页面不会调用转写/改写/视频生成，也不会扣费。

### B. IP 场景形象照 → 人物置换

对应审核图：10 → 15B → 04A → 04 → 03。

1. 人物库选择张工，进入形象资料，点击“庭院讲解”的“用于人物置换”。
2. 如果已有置换草稿，则返回该草稿并更新目标人物参考；从人物库独立开始时，新建置换草稿。
3. 带入人物身份、场景形象/人物版本、目标参考资产及来源页面，不仅传一条临时图片URL。
4. 04A明确显示“来自人物库 · 张工 / 庭院讲解 / V2”；右侧是目标人物参考。
5. 若还没有原始画面，左侧为空，并要求上传图片或从视频选帧；生成按钮禁用。
6. 不把目标人物照片自动填入原始画面，不把五视图整张拼合图直接当作一帧输入。
7. 有原始画面后核对置换要求，执行首帧准备的独立提交确认；费用未就绪不能提交。
8. 04展示原始画面与置换首帧预览，用户确认后才把首帧结果带入后续视频创作。
9. 同一个人物换场景时保留原始画面，原有置换预览与确认失效；换人物也必须同步换目标场景，不能留下上一人物的照片。

03作为“选择继续复刻编辑”分支，带入张工庭院置换首帧，只更新选中的镜头；其他镜头保持原稿。若用户选择图生视频，则回填图生草稿的首帧槽，不覆盖结束帧。

验收：无原始画面时不能生成；目标人物照始终位于目标参考区；换场景后不会复用旧首帧；结果仍是首帧，不被标记为已完成整段人物视频置换。

## 4. 全部跨模块跳转清单

以下“携带内容”为建议的业务字段，不是本轮新建的API合同。实际开发应匹配现有版本化资产与客户权限体系。

| 编号 | 起点和动作 | 去向 | 携带内容与到达状态 | 回退/禁止行为 |
|---|---|---|---|---|
| F01 | 工作台选择视频复刻并导入 | 视频复刻草稿 | 来源视频引用；上传/解析状态 | 导入失败留在原页，允许上传兜底；不自动生成 |
| F02 | 工作台选择数字人口播、提取文案 | 口播内容草稿 | 来源引用、转写任务与结果 | 不先强制选IP，不走完整画面拆解 |
| F03 | 爆款视频卡片/详情：复刻画面 | 视频复刻导入 | 作品引用、平台/作者/来源、可用媒体引用 | 不假定长视频符合短片上传限制；必要时选片段 |
| F04 | 爆款视频：提取文案做口播 | 口播提取页 | 同一来源与已存在的可用转写 | 视频简介不可冒充全文；解析失败可上传 |
| F05 | 文案工坊：从视频提取 | 来源选择/转写 | 当前文案草稿ID、来源选项、返回目标 | 结果回填当前原文区，不另开丢失上下文的空白编辑页 |
| F06 | 文案工坊：按IP改写 | 当前文案结果区 | 原文、选定IP定位快照、用户要求 | 创建新版本；不能静默覆盖已确认终稿 |
| F07 | 文案工坊：生成数字人口播 | 20E或20B | 终稿版本/正文快照、IP、来源、返回位置 | 已确认走20E；草稿走20B；不重复转写/改写 |
| F08 | 人物库：查看IP档案 | 15A–15E | 当前人物身份及选中页签 | 返回恢复人物列表筛选和位置 |
| F09 | 场景照片：用于人物置换 | 04A或已有04草稿 | 人物身份、场景版本、目标图、草稿及返回上下文 | 原始画面独立；不直接提交生成 |
| F10 | 人物置换：更换人物，或更换场景 | 人物或场景选择器 | 当前目标人物、用途、原草稿 | 换场景仅显示当前IP；换人物先选身份再选该人的场景，确认时一起替换，取消保留原选择 |
| F11 | 人物置换：确认首帧并继续 | 复刻编辑/图生视频草稿 | 已确认首帧资产、来源帧、人物场景版本、生成描述 | 用户选择目标创作方式；不能直接收费生成视频 |
| F12 | 人物库：用于数字人口播 | 口播草稿 | IP与可用口播形象/默认声音 | 无终稿先准备文案；普通照片不充当数字人 |
| F13 | 口播：更换IP | 当前口播草稿 | 保留原文与已有文案历史，读取新IP定位 | 清掉旧IP声音/形象/报价；要求重新核对当前文案 |
| F14 | 口播：更换声音/口播形象 | 当前IP资产选择器 | 用途=口播、当前IP、当前草稿 | 只允许可用且授权有效的资产；取消原样返回 |
| F15 | 口播：去准备口播形象 | 当前人物15C | 人物身份、原口播草稿和返回目标 | 先保存草稿；训练期间不可提交；完成/取消都回原草稿 |
| F16 | 口播：去试听确认声音 | 当前人物15D | 当前声音版本、人物身份、原草稿 | 确认后重新校验可用状态再回填，不仅修改前端标签 |
| F17 | 口播/置换：补充授权 | 当前人物15E | 缺失的肖像或声音授权类型、原草稿 | 两类授权分开；不可用时保留草稿但禁提交 |
| F18 | 素材库：视频用于创作 | 用途选择后进入草稿 | 来源资产及类型、原草稿可选 | 复刻画面/提文案做口播分开，不全走同一接口 |
| F19 | 素材库：图片用于创作 | 图生/参考生视频，或置换的原始画面 | 明确用途和图片资产 | 普通素材图片不能自动成为目标人物身份 |
| F20 | 素材库：配音/环境音复用 | 支持该音频用途的草稿 | 音频资产、类型、时长与用途 | 普通音频不能自动填入“已克隆声音”；适配不支持时不显示入口 |
| F21 | 视频生成：从人物库选择参考 | 同用途资产选择器后回填 | 人物/场景版本、目标参考槽位 | 不覆盖首帧或其他素材槽；必须符合模式能力 |
| F22 | 口播/视频：继续确认 | 各自生成确认页 | 冻结候选输入、授权状态、费用报价状态 | 缺终稿/资产/权限/有效报价均禁提交 |
| F23 | 用户最终确认并生成 | 任务详情/任务中心 | 已创建的同一个任务标识 | 防重复提交；提交不确定时核对，不盲目再创建 |
| F24 | 任务中心：查看进度/结果 | 对应任务详情 | 任务类型、产物、状态、创建时配置快照 | 返回恢复原任务列表筛选；不加载后来修改的IP默认值冒充旧任务 |
| F25 | 已知失败任务：继续处理 | 重试确认页09A | 可复用步骤、待重试步骤、费用变化 | 不重复生成已成功配音/数字人；不确定受理结果不提供直接重提 |
| F26 | 结果：复用此配置 | 新创作草稿 | 终稿/素材引用及允许复用的配置 | 新草稿重新校验资产/授权/报价，不直接运行旧任务 |
| F27 | 结果：去发布管理 | 发布草稿12 | 稳定的任务ID、结果ID/版本、交付模式DIRECT或MANAGED_ASSET、终稿版本、标题/描述候选 | 不以临时播放URL作为业务主键；按结果标识获取可用交付地址；链接失效禁发布，且不改标已入素材库 |
| F28 | 发布管理：修改发布文案 | 当前发布草稿 | 平台文案版本 | 不反向覆盖已生成视频的口播终稿 |
| F29 | 发布管理：确认发布 | 发布任务详情 | 用户确认的成片和发布内容版本、有效账号 | 无发布权限或账号失效不能提交 |
| F30 | 结果：下载/保存素材 | 下载或独立素材保存任务 | 成片引用与可用交付链接 | H3直链≠云素材；保存成功才标已入库，失败不影响已有任务结果 |

F20中的复用音频属于独立输入方式；仅在所接生成能力支持时开放。第一版“终稿＋声音合成口播”不得仅因素材库有录音就切换成音频驱动绕过终稿确认。

## 5. 统一草稿与返回规则

跨模块使用可恢复的创作草稿作为中心，不依赖仅存在于当前页面内存的临时对象。

建议草稿关联：

- 创作草稿ID、创作类型、当前子页与已完成准备项。
- 来源引用（作品/上传媒体/手写文案）；原始转写及原始画面分别记录。
- 文案版本、终稿确认所对应的版本；IP身份与定位快照。
- 目标人物/场景版本、口播形象版本、声音版本；这三类引用不能共用一个模糊的“人物图片”字段。
- 来源入口、返回页面/页签、列表筛选与滚动位置。
- 可用性校验与费用状态；供应商敏感标识只留后台，不带进前端URL。

离开编辑器前先保存成功，才能跳出补资产；保存失败留在当前页并提示，不让用户带着“已保存”的假状态离开。取消资产选择不改当前草稿。重新进入时重新检查资产和授权，但不静默改用另一个人或声音。

人物卡片点击、选择素材、选择IP、进入确认页本身均不等于付费生成。报价获取只有显式进入费用确认后进行；是否扣费以最终提交及实际结算规则为准。

## 6. 变更后哪些内容要重新确认

| 变化 | 保留 | 失效或重新核对 |
|---|---|---|
| 更换来源视频 | 人物选择可保留；旧稿作为历史版本保留 | 新来源转写、当前终稿确认、报价；复刻的分镜/首帧也失效 |
| 编辑终稿 | 来源、IP、声音、口播形象 | 新正文生成新版本，终稿确认与报价失效 |
| 切换人物IP | 原始转写与旧改写版本 | 旧声音、口播形象、授权摘要、报价清空；文案需重新核对，可改写或保留文字重新确认 |
| 同一IP更换声音 | 终稿与口播形象 | 试听/声音就绪检查和报价；已有配音及下游视频不可当作新声音结果 |
| 同一IP更换口播形象 | 终稿、声音 | 形象可用性检查与报价；旧数字人视频不再匹配 |
| 更换置换原始画面 | 目标人物与场景可保留 | 置换预览、首帧确认、报价 |
| 更换目标人物或场景版本 | 置换原始画面 | 目标参考确认、旧首帧、后续生成确认与报价 |
| 资产被撤销、授权过期 | 用户原稿和历史选择记录 | 对应资产提交资格与报价；必须显式重新选择或补授权 |
| 修改IP默认声音/默认形象 | 已提交任务的冻结快照 | 不回写历史任务；新草稿才读取新默认值 |
| 报价超时或影响费用的配置变化 | 草稿内容 | 报价失效、提交禁用，用户重新确认 |
| 修改发布标题或描述 | 生成视频和口播终稿 | 仅发布内容确认失效，不重做已生成视频 |

## 7. 资产选择器和异常处理

同一套选择器外壳，按用途过滤，不向所有场景提供所有资产。

- 人物置换选择“目标人物＋场景版本”；图生视频选择“首帧图片”；参考生视频按图片/视频/音频槽选择；口播选择“已就绪口播形象＋已确认声音”。
- 默认为当前IP资产。切到另一人物的资产时，需要明确同步切换IP，不能把李总的声音配给张工而不提示。
- 五视图展示一张拼合图；系统内部可保留衍生视角资产，用户不需要逐张选五张或七张。
- 空库：创建入口；有身份无场景：去准备场景；无口播模型：去准备模型；声音待确认：去试听；训练中：显示处理中并可返回草稿。
- 失败：保留输入和成功产物，提供相应重试/更换资产；受理不明：等待核对，不直接重提。
- 无权限、跨用户资产、授权过期、已撤销资产：不允许生成；保留草稿并说明哪一项需处理。最终提交时仍须服务端校验，不能只靠前端禁用。
- 结果链接过期：明确显示过期并提供重新获取/处理入口，不将空白播放器解释为“素材已入云但丢失”。

## 8. 费用与提交状态

20C和09A重点展示“费用尚未就绪，不能提交”的状态。因为数字人口播计费口径尚未确定，本轮不编造人民币、积分或按条扣费数字。

正式界面还必须支持：未请求报价 → 报价中 → 报价成功且未过期 → 用户确认 → 提交中 → 已创建任务；以及报价失败/过期、余额不足、提交受理不明等状态。

报价成功态必须展示服务端实际返回的计费单位、预计消耗和本次执行范围；用户确认后才能启用最终提交。报价成功不得自动触发任务。费用或输入变化后原确认失效。此处为待真实计费合同确定后的实施验收要求，不拿虚构数值填图。

## 9. 本轮审核与后续开发边界

本轮交付：28张效果图、模块衔接文档、可填写意见的审核图册。图册按业务链翻页仅用于看图，不调用业务接口。

后续实施需要单独验证：

1. 文案跳转逐字一致、版本不可漂移、零重复转写/改写/扣费。
2. 场景照跳转目标正确，原始画面与人物参考不串位；变更后旧首帧失效。
3. 草稿离开、取消、刷新、补资产返回均不丢内容；切IP不混用旧声音/形象。
4. 资产权限与两类授权在提交时复核；声音待确认/模型训练中不能提交。
5. 任务重试复用已完成阶段，不重复付费；受理不明走核对。人物置换切换人物时，身份与场景一起更新，绝不出现李总身份配张工照片的中间组合。
6. 进入发布管理不自动发布，修改发布文案不改口播终稿。
7. H3直链交付、公共素材和口播中间文件分别处理；保存素材结果真实可追溯。
8. 图片中的文生视频/参考生视频是设计目标，当前真实H3实现仍需分别对照接口能力验收。

本轮没有正式前后端开发、真实API调用、云上传或发布操作。采集API参数由用户提供，不进行网上接口搜索。
