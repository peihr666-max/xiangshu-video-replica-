# V1.3 数字人口播整合效果图审核说明

打开同级的“00-打开审核.html”。本地文件方式和静态 HTTP 地址均可使用，不需要网络、CDN 或接口服务。

## 审核方法

1. 点击“从工作台开始审核”查看页面清单中的全部效果图。
2. 可点击“优先审核数字人口播”直接从 20A 开始，或点击“优先审核人物详情”直接从 15A 开始。
3. 可按业务链审核：“文案→口播”按 08→20E→20C→20D→12 查看；“人物→置换”按 10→15B→04A→04→03 查看。查看器标题会标明“业务链顺序”，关闭后恢复全部页面顺序。
4. 大图中使用左右方向键切换，Esc 关闭；也可点击“打开原图”。
5. 使用“模块”和“结论”筛选页面，在每张图下记录“待审核 / 通过 / 需调整”及具体意见。
6. 离开前点击“导出审核意见”，保存 Markdown 文件。浏览器本地记录只作辅助，更换浏览器或访问地址时不保证延续。

## 优先审核内容

- 工作台是否能让用户清楚选择“视频复刻”或“数字人口播”。
- 人物库是否以一个人物 IP 统一管理定位、形象资料、口播形象、声音和授权状态。
- 五视图是否表现为一张合成图片；同一个人是否可以拥有不同场景形象照。
- 数字人口播是否形成“导入文案 → 选择人物与声音 → 确认生成 → 成片结果”的简洁流程。
- “文案二创 → 数字人口播”和“IP 场景形象 → 人物置换”的入口表达是否连贯。详细关系见“00-模块衔接与跳转需求.md”。
- 失败任务是否保留已完成结果并允许从失败节点续作；不能暗示整单重新扣费或全部重做。
- 20F 应保持“李总”同一人物 IP 的上下文。15D 是张工的通用声音示例，两张图不能被理解为同一个人的直接跳转。
- 爆款视频详情是否同时支持“复刻画面”和“提取文案做口播”。
- 20C 的费用必须显示“待报价”，生成按钮必须禁用，不能表现为已经可以付费生成。
- 生成完成与发布应保持分离，不应暗示自动发布。

## 范围说明

这是供审核的静态效果图册，不是正式业务前端。图册中的“按业务链审核”只是改变图片查看顺序；效果图内的按钮和链接只用于评审交互意图，不能真的执行跨模块业务跳转。所有人物、视频、声音、数据、任务和结果均为示例内容；没有连接真实 API，没有执行视频生成、数字人生成、云存储、收费或发布。

本图册使用独立存储键 `zhongshu-ai-v13-oral-integration-20260905-review`，不会读取或覆盖 V1.2 图册的审核意见。
